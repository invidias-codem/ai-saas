# Tiered Memory, The Vault, and Safer Recoveries

We're starting 2026 with a massive upgrade to Lattice OS's core architecture. This update isn't just about new features—it's about making Lattice OS deeper, safer, and more organized.

We’ve overhauled how Lattice OS remembers, how you manage your conversation history, and how we protect your data. Let’s dive in.

## 🧠 Tiered Memory: Personal vs. Contextual

Until now, Lattice OS's memory was mostly flat. If you told Lattice OS your name in one chat, it might remember it later, but it was mixed in with random facts about that specific coding problem you were solving.

We've introduced a **Tiered Memory System** with **Auto-Promotion**:

1.  **Conversation Scope:** Detailed facts, code snippets, and context specific to the *current* chat. These stay isolated so they don't pollute other conversations.
2.  **User Scope (The "Core"):** When Lattice OS detects high-confidence personal facts (like your preferred tech stack, your name, or project preferences), it **auto-promotes** them to your User Profile.

**What this means:**
You can start a brand new chat, and Lattice OS immediately knows you prefer TypeScript over JavaScript and Tailwind over CSS, without you saying a word. But it *won't* hallucinate variable names from that unrelated project you worked on last week.

## 🗄️ The Vault: Your Complete History

We've completely redesigned how you access past conversations. Say hello to **The Vault**.

Available under **Settings > Vault**, this is your command center for memory management. It's not just a list anymore; it's a powerful tool to:
- **Search** across all your past conversations.
- **Filter** by Active, Archived, or Deleted status.
- **Track** exactly how many messages are in each chat (we fixed those counters to be 100% accurate!).

## ⏰ 30-Day Recovery Window

Accidentally deleting a chat used to be final. Not anymore.

We've implemented a **Soft Delete** system with a **30-Day Recovery Window**.
- When you delete a conversation, it moves to the "Deleted" tab in The Vault.
- You have **30 days** to restore it with a single click.
- A color-coded badge shows you exactly how many days are left before permanent deletion.
- After 30 days, our automated cron job wipes it forever to keep your data clean.

Safety first, always.

## 🔒 True Chat Isolation

We heard your feedback about "message bleeding"—where snippets of an old conversation would eerily appear in a new one.

We tracked this down to an over-zealous cloud sync merging strategy. We've completely rewritten the synchronization logic:
- **Conversation-Scoped Sync:** Every sync event is now strictly bound to its specific Conversation ID.
- **Storage Isolation:** Browser session storage is now namespaced per conversation.

Start a new chat, and it is truly a blank slate.

## 🤖 Researcher Agent Enhancements

Our Researcher Agent just got smarter. We've integrated a **Reinforcement Learning Loop**:
- It now "learns" from successful searches.
- If a specific search strategy yields good results, it remembers that pattern for next time.
- It can extract knowledge from successful API calls and store them for future reference.

## Under the Hood

For the developers curious about the technical details, we pushed 22 files and over 3,000 lines of code in this update, including:
- **SQL Migrations:** New schemas for `memory_bank`, `learning_patterns`, and `knowledge_graph`.
- **Vector Search:** Optimized `pgvector` queries for retreiving the right memory at the right time.
- **Performance:** Direct SQL counting for message stats instead of expensive joins.
