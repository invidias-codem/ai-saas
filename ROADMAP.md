# Genie AI Roadmap

> A prioritized list of planned enhancements for Genie's Slack integration.

---

## Phase 1: Foundation (Q1 2026)

### ✅ Completed
- [x] Thread-level memory within conversations
- [x] File analysis (PDF, code files, text)
- [x] Link content extraction and summarization
- [x] Code detection with language-specific handling
- [x] Streaming responses for faster feedback

### 🔄 In Progress
- [ ] **Cross-Session Memory**: Remember user preferences and context across different threads
- [ ] **Image Analysis**: Support for image files using Vision API
- [ ] **Expanded File Types**: Excel, CSV data analysis, Word documents

---

## Phase 2: Intelligence (Q2 2026)

### Proactive Features
- [ ] **Scheduled Summaries**: Daily/weekly channel digest
- [ ] **Anomaly Detection**: Alert on unusual patterns in conversations
- [ ] **Smart Reminders**: Context-aware follow-up suggestions

### External Integrations
- [ ] **MCP (Model Context Protocol)**: Connect to external tools and APIs
- [ ] **GitHub Integration**: PR reviews, issue creation, code search
- [ ] **Jira/Linear Integration**: Create and update tickets from Slack

---

## Phase 3: Automation (Q3-Q4 2026)

### Slack Ecosystem
- [ ] **Channel Management**: Create, archive, manage channels via commands
- [ ] **Workflow Builder**: Custom AI-powered workflow steps
- [ ] **User Onboarding**: Automated welcome messages with context

### Advanced Memory
- [ ] **Knowledge Base**: Team-wide shared knowledge from conversations
- [ ] **Semantic Search**: Find past conversations by meaning, not keywords
- [ ] **User Profiles**: Personalized responses based on user history
