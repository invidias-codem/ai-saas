## Detailed Setup Instructions

### Firebase Cloud Functions Deployment

1. **Prepare environment**:
   ```bash
   cd functions
   npm install
   ```

2. **Create `.env` file in `functions/` directory** with these variables:
   ```bash
   GOOGLE_CLOUD_PROJECT=genie-ai-1ca85
   GOOGLE_CLOUD_REGION=us-central1
   VERTEX_AI_LOCATION=us-central1
   VERTEX_AI_MODEL_TEXT_EMBEDDING=text-embedding-004
   VERTEX_AI_MODEL_GEMINI=gemini-2.5-flash
   
   # Copy Zapier/Slack secrets from main .env.local
   ZAPIER_WEBHOOK_SECRET=...
   SLACK_BOT_TOKEN=...
   SLACK_SIGNING_SECRET=...
   ```

3. **Deploy Cloud Functions**:
   ```bash
   firebase deploy --only functions
   ```

### Zapier Setup

1. **Create Zapier App** (Developer Platform):
   - Go to https://developer.zapier.com
   - Create new app
   - Set **OAuth Scopes**: `read`, `write`
   - Set **Redirect URL**: `https://yourdomain.com/api/integrations/zapier/callback`
   - Note your `Client ID` and `Client Secret`

2. **Create Zapier Zaps** to trigger on:
   - New memory created
   - Conversation completed
   - Usage milestone reached
   - Export data to CRM/database

3. **Webhook Configuration**:
   - Endpoint: `/api/integrations/zapier/webhooks`
   - Events: `memory.created`, `conversation.completed`, `interaction.logged`

### Slack Bot Setup

1. **Create Slack App**:
   - Go to https://api.slack.com/apps
   - Create "From scratch"
   - Basic info → Copy `App ID` and `Client Secret`

2. **Enable Features**:
   - Slash Commands: `/genie`
   - Interactive Components: Allow modals and buttons
   - Event Subscriptions
   - OAuth Scopes:
     - `commands`
     - `chat:write`
     - `users:read`
     - `channels:manage`

3. **Set OAuth Redirect URL**:
   ```
   https://yourdomain.com/api/integrations/slack/callback
   ```

4. **Slash Commands** (under Slash Commands):
   - Command: `/genie`
   - Request URL: `https://yourdomain.com/api/integrations/slack/webhooks` (Cloud Function)
   - Short Description: "Interact with Genie AI"

5. **Install App to Workspace**:
   - Go to OAuth & Permissions
   - Click "Install to Workspace"
   - Authorize when prompted

### Firestore Setup

The following collections are automatically created:

```
users/
  ├── {userId}/
      ├── memories/           # Stores conversation history & interactions
      ├── ragIndex/          # Vector index for semantic search
      ├── interactions/      # Analytics events
      ├── context/
      │   └── profile/       # User preferences & stats
      └── integrations/
          ├── zapier/        # Zapier webhook config
          └── slack/         # Slack integration config
```

### Firestore Security Rules

Add to your `firestore.rules`:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Require authentication for user data
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth.uid == userId;
    }
    
    // Allow Cloud Functions to write
    allow write: if request.auth.uid != null;
  }
}
```

## Troubleshooting

### Cloud Functions not working
- Check function logs: `firebase functions:log`
- Verify environment variables in Cloud Console
- Ensure Vertex AI API is enabled in Google Cloud

### Slack commands not responding
- Verify signing secret matches
- Check Cloud Function logs for webhook calls
- Ensure bot has required permissions

### RAG Memory not retrieving context
- Check Firestore indices exist
- Verify `RAG_CLOUD_FUNCTION_URL` is set correctly
- Check embedding generation in `ragMemoryService.ts`

## Cost Optimization

1. **Vertex AI Embeddings**: Monitor usage, consider caching
2. **Firestore**: Set up TTL policies for old memories
3. **Cloud Functions**: Use shorter timeout for webhook integrations
4. **Storage**: Archive old memories to Cloud Storage after 1 year
