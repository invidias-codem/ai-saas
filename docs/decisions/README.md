# Architectural Decision Records (ADRs)

This directory stores short records of important architectural decisions in Genie AI / `ai-saas`.

## Purpose

ADRs help preserve:
- what was decided
- why it was decided
- what problem it solved
- what tradeoffs were accepted

They are especially useful in a fast-moving codebase where architecture can otherwise become trapped in chat history, branch context, or personal memory.

## ADR Style

Each ADR should be short and explicit:
- Status
- Context
- Decision
- Consequences

The goal is clarity, not ceremony.
