# เอกสาร Lattice OS

เอกสารนี้จัดทำขึ้นเพื่อให้ผู้พัฒนา ผู้ร่วมพัฒนา ผู้ตรวจสอบ และผู้ดูแลระบบในอนาคตเข้าใจซอร์สโค้ดและพฤติกรรมของแพลตฟอร์ม Lattice OS ได้อย่างชัดเจน

เราให้ความสำคัญกับความชัดเจนมากกว่าการตลาด

## หลักการจัดทำเอกสาร

- อธิบายว่าระบบทำอะไรจริง
- แยกพฤติกรรมที่เสถียรออกจากสถาปัตยกรรมที่กำลังพัฒนา
- ทำให้ขอบเขตความไว้วางใจเห็นได้ชัดเจน
- บันทึกการเลือกใช้เทคโนโลยีจริงอย่างตรงไปตรงมา
- ใช้คำอธิบายที่เป็นรูปธรรมแทนคำกล่าวกว้าง ๆ เกี่ยวกับ AI

## เอกสารที่ใช้งานอยู่

### CLI และการติดตั้ง (ใหม่)
- **lattice-cli v0.3.0** — CLI ที่พร้อมใช้งานจริงสำหรับจัดการการติดตั้งผ่าน Docker
  - ตำแหน่ง: `scripts/lattice-cli/`
  - ความสามารถ: การยืนยันตัวตน การติดตั้ง การเปิดใช้งานใบอนุญาต V3 การตรวจสอบสถานะ การอัปเกรด และการสำรองข้อมูล
  - กระบวนการติดตั้ง: ตรวจสอบความพร้อม (Docker, Compose v2, RAM/CPU, พอร์ต ดิสก์ และการยืนยันตัวตน Docker) พร้อมตรวจสอบใบอนุญาตระหว่างติดตั้ง
  - CI/CD: สร้างไบนารีอัตโนมัติผ่าน GitHub Actions
  - การแจกจ่าย: สคริปต์ `install.sh` ที่ตรวจจับระบบปฏิบัติการและสถาปัตยกรรมเครื่อง
  - ดู: `scripts/lattice-cli/README.md` สำหรับรายการคำสั่งฉบับเต็ม

### โปรแกรมเบต้า (ใหม่)
- **สื่อสำหรับเชิญเข้าร่วมทดสอบเบต้า**: `docs/beta-outreach/`
  - เทมเพลตข้อความส่วนตัวบน Threads (ไม่เกิน 200 อักขระ)
  - ลำดับอีเมลสำหรับผู้ทดสอบที่สนใจ
  - กลยุทธ์การสื่อสารตามกลุ่มผู้ใช้
  - การจัดการคำตอบ เช่น “ใช่”, “คืออะไร?”, “ฟรีไหม?” และ “ยังไม่ใช่ตอนนี้”

- **คู่มือเริ่มต้นใช้งานเบต้า**: `app/[locale]/(public)/beta/`
  - เริ่มต้นอย่างรวดเร็ว (15 นาที) - `/beta/start`
  - เส้นทางนักพัฒนา (45 นาที) - `/beta/dev`
  - เส้นทางองค์กร (1 ชั่วโมง) - `/beta/enterprise`
  - เส้นทางความเป็นส่วนตัว (1 ชั่วโมง) - `/beta/privacy`
  - สร้างหน้าเว็บแบบสแตติกเพื่อให้โหลดได้รวดเร็ว

### การยืนยันตัวตน (อัปเดต)
- **ประสบการณ์เข้าสู่ระบบที่ได้แรงบันดาลใจจาก PS1/PS2**
  - ปรับแต่ง Clerk ด้วยการ์ดเอฟเฟกต์กระจก
  - พื้นหลังเคลื่อนไหวพร้อมอนุภาคเล็กน้อย
  - สไตล์ย้อนยุคร่วมสมัย (ความทรงจำจากเกมยุค 90)
  - ตำแหน่ง: `app/[locale]/(auth)/layout.tsx`
