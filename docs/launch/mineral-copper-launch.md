# Mineral / Copper — Lattice Product Hunt brand candidate

Draft only. Not deployed/merged or replacing the root homepage.

The source logo favicon is a white triangular geometric mark on black;
this design preserves that contrast rather than reusing the violet/blue
gradient. Lattice's PWA manifest uses near-black #080A0D.

Palette:
- Mineral Ink #101916 (logo and architectural dark)
- Limestone #F2EFE5 (light canvas and dark foreground)
- Forest Green #34755D (nodes, progress and connected systems)
- Copper #CD7A53 (primary actions and emphasis)
- Mist Sage #A5B7A6 (secondary surfaces and guidance)

The local companion bundle includes a more detailed L1/L2 preview. This
repository route independently implements the same theme direction.

The route is /en/launch, is public through proxy.ts, redirects other
locales to en, and is noindexed until launch QA. It preserves the existing
root A/B/C landing experiment and authenticated UI tokens.

Requirements before launch: real product screenshots and honest
captions; 320/375/390px manual mobile Safari + desktop QA; contrast and
keyboard QA; production sign-in to completed Code Builder build; marketing
copy/legal review; Product Hunt launch media. Do not enable sandbox
sharing merely for the demo.
